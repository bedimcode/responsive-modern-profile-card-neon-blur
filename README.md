# Insane Responsive Neon Blur Profile Card

This project is part of a YouTube tutorial in which we build a insane responsive neon blur profile card from scratch using HTML CSS & JavaScript

## 🎬 [Watch the Demo & Code](https://youtu.be/lvk2sse9Avw) 

![preview img](/preview.png) 

### 📌 Project Features 
- Fully Responsive Neon Blur Profile Card (Mobile First Methodology).
- Clear and semantic HTML structure.
- Use of CSS variables.
- With interactive buttons.
- Neon effect on the card.
- Glass effect on social and data.
